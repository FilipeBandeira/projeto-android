# Página sobre Android

Página informativa desenvolvida durante o Curso em Vídeo. O nome refere-se ao tema da página; a implementação é um site em HTML e CSS.

## Tecnologias e funcionalidades

**HTML5 e CSS3**

- Estrutura de artigo com títulos, imagens e conteúdo multimídia.
- Estilização com fontes e recursos locais.

## Como executar

Requisitos: navegador moderno. Para o servidor local abaixo, Python 3.

```sh
git clone https://github.com/FilipeBandeira/projeto-android.git
cd projeto-android
python3 -m http.server 8000
```

Abra `http://localhost:8000`. O servidor local apenas entrega os arquivos estáticos.

## Organização

- `index.html`: página principal.
- `style/`: folhas de estilo.
- `imagens/` e `fontes/`: recursos visuais.

## Escopo

Projeto educacional que registra a prática de desenvolvimento web. Recursos de terceiros, como fontes e conteúdo incorporado, podem exigir internet.
